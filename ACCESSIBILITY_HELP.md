# Решение проблемы с Accessibility Service

## Проблема: "Не могу предоставить специальные возможности"

Это происходит на некоторых телефонах (особенно Xiaomi, Huawei, Samsung).

## Решения:

### Способ 1: Через настройки специальных возможностей

1. Откройте **Настройки** телефона
2. Найдите **Специальные возможности** (или **Accessibility**)
   - На Xiaomi: Настройки → Расширенные настройки → Специальные возможности
   - На Samsung: Настройки → Специальные возможности
   - На Huawei: Настройки → Специальные возможности
3. Найдите **Установленные службы** или **Службы**
4. Найдите **AutoVPN** в списке
5. Включите переключатель
6. Подтвердите предупреждение системы

### Способ 2: Через настройки приложения

1. Откройте **Настройки** → **Приложения**
2. Найдите **AutoVPN**
3. Нажмите **Разрешения** или **Permissions**
4. Найдите **Специальные возможности**
5. Включите

### Способ 3: Для Xiaomi (MIUI)

1. **Настройки** → **Приложения** → **Управление приложениями**
2. Найдите **AutoVPN**
3. **Другие разрешения** → включите **Отображение всплывающих окон**
4. **Автозапуск** → включите
5. **Батарея и производительность** → **Нет ограничений**
6. Затем: **Настройки** → **Расширенные настройки** → **Специальные возможности** → **Установленные службы** → **AutoVPN** → Включить

### Способ 4: Для Samsung

1. **Настройки** → **Приложения**
2. Найдите **AutoVPN** → **Разрешения**
3. **Специальный доступ** → **Специальные возможности**
4. Включите **AutoVPN**

### Способ 5: Для Huawei

1. **Настройки** → **Приложения**
2. **AutoVPN** → **Разрешения**
3. Включите все необходимые разрешения
4. **Настройки** → **Специальные возможности** → **AutoVPN** → Включить

### Способ 6: Если ничего не помогает

Некоторые производители блокируют Accessibility Service для сторонних приложений.

**Альтернативное решение:**
Мы можем изменить приложение, чтобы оно использовало **UsageStatsManager** вместо AccessibilityService.

Это требует другое разрешение, которое легче получить:
- **Настройки** → **Приложения** → **Специальный доступ** → **Доступ к статистике использования** → **AutoVPN** → Включить

## Проверка работы

После включения службы:
1. Откройте AutoVPN
2. Статус должен показывать "Служба включена"
3. Добавьте YouTube в список
4. Откройте YouTube
5. VPN должен запуститься автоматически
