# Инструкция по использованию AutoVPN

## Установка и настройка

### 1. Сборка приложения

```bash
cd AutoVPN
./gradlew assembleDebug
```

APK будет находиться в `app/build/outputs/apk/debug/app-debug.apk`

### 2. Установка на устройство

```bash
adb install app/build/outputs/apk/debug/app-debug.apk
```

Или перенесите APK на устройство и установите вручную.

### 3. Настройка разрешений

**Важно!** Приложению требуется разрешение Accessibility Service:

1. Откройте **Настройки** → **Специальные возможности**
2. Найдите **AutoVPN** в списке служб
3. Включите службу
4. Подтвердите предупреждение системы

### 4. Выбор VPN-клиента

1. Откройте AutoVPN
2. Нажмите кнопку **"Выбрать VPN клиент"**
3. Выберите установленный VPN-клиент из списка:
   - Hiddify
   - v2rayNG
   - Shadowsocks
   - Clash for Android
   - Surfshark

**Примечание:** VPN-клиент должен быть установлен и настроен заранее.

### 5. Добавление приложений

1. Нажмите кнопку **+** (плюс) внизу экрана
2. Выберите приложение из списка (например, YouTube или Telegram)
3. Приложение появится в списке отслеживаемых

### 6. Включение службы

Переключите тумблер **"Служба мониторинга"** в положение **Включена**.

## Как это работает

1. Когда вы открываете одно из отслеживаемых приложений (например, YouTube)
2. AutoVPN автоматически запускает выбранный VPN-клиент
3. VPN-клиент устанавливает соединение (если настроен)
4. Вы можете пользоваться приложением через VPN

## Поддерживаемые VPN-клиенты

| Клиент | Package Name | Автозапуск |
|--------|--------------|------------|
| Hiddify | com.hiddify.app | ✅ |
| v2rayNG | com.v2ray.ang | ✅ |
| Shadowsocks | com.github.shadowsocks | ✅ |
| Clash for Android | com.github.kr328.clash | ⚠️ Открывает приложение |
| Surfshark | com.surfshark.vpnclient.android | ⚠️ Открывает приложение |

**Примечание:** Некоторые клиенты не поддерживают прямой запуск VPN через Intent, поэтому приложение просто открывает их.

## Рекомендуемые приложения для мониторинга

- YouTube (`com.google.android.youtube`)
- Telegram (`org.telegram.messenger`)
- Instagram (`com.instagram.android`)
- Twitter/X (`com.twitter.android`)
- Facebook (`com.facebook.katana`)

## Устранение неполадок

### VPN не запускается автоматически

1. Убедитесь, что служба Accessibility включена
2. Проверьте, что VPN-клиент установлен и настроен
3. Попробуйте вручную запустить VPN-клиент для проверки

### Приложение не отслеживается

1. Убавьте, что приложение добавлено в список
2. Перезапустите службу (выключите и включите тумблер)
3. Проверьте разрешения Accessibility

### Служба не включается

1. Перейдите в **Настройки** → **Приложения** → **AutoVPN**
2. Очистите кэш и данные
3. Переустановите приложение

## Безопасность

- Приложение использует только локальные разрешения
- Не собирает и не передаёт данные
- Не имеет доступа к интернету (кроме запуска VPN)
- Открытый исходный код

## Ограничения

- Работает только с установленными VPN-клиентами
- Требует Android 7.0+
- Некоторые производители (Xiaomi, Huawei) могут блокировать фоновую работу
- На Android 12+ может потребоваться дополнительная настройка

## Оптимизация батареи

Для стабильной работы отключите оптимизацию батареи:

1. **Настройки** → **Батарея** → **Оптимизация батареи**
2. Найдите **AutoVPN**
3. Выберите **"Не оптимизировать"**

## Разработка

Проект использует:
- **Язык:** Kotlin
- **UI:** Jetpack Compose
- **Минимальная версия:** Android 7.0 (API 24)
- **Целевая версия:** Android 14 (API 34)
