# Диагностика проблемы AutoVPN

## Проверка через ADB (если телефон подключен к компьютеру)

```bash
# 1. Проверьте, что телефон подключен
adb devices

# 2. Очистите логи
adb logcat -c

# 3. Запустите мониторинг логов AutoVPN
adb logcat | grep AppMonitorService

# 4. Теперь откройте YouTube на телефоне
# Вы должны увидеть в логах:
# "Detected monitored app: com.google.android.youtube"
# "Started VPN client: org.outline.android.client"
```

## Если нет ADB - проверьте вручную:

### 1. Проверьте Accessibility Service:
- Настройки → Специальные возможности → Установленные службы
- Найдите "AutoVPN" 
- Должен быть **ВКЛЮЧЕН** (не просто в списке, а именно включен)

### 2. Проверьте в самом AutoVPN:
- Откройте AutoVPN
- "Служба мониторинга" должна показывать "Включена"
- Если показывает "Выключена" - нажмите на переключатель

### 3. Проверьте список приложений:
- В AutoVPN должен быть добавлен YouTube
- Package name должен быть: `com.google.android.youtube`

### 4. Проверьте VPN клиент:
- В AutoVPN должен быть выбран "Outline"

## Возможные проблемы:

### Проблема 1: Accessibility Service не работает
**Симптом:** Служба показывает "Включена" в AutoVPN, но в системных настройках выключена

**Решение:**
1. Настройки → Приложения → AutoVPN → Принудительная остановка
2. Настройки → Специальные возможности → AutoVPN → Включить
3. Перезапустите AutoVPN

### Проблема 2: Outline не запускается через Intent
**Симптом:** AutoVPN работает, но Outline не открывается

**Решение:** Нужно изменить код для Outline (я могу это сделать)

### Проблема 3: YouTube не отслеживается
**Симптом:** Другие приложения работают, но YouTube нет

**Решение:** Проверьте, что добавлен именно YouTube, а не YouTube Music или другое приложение

## Быстрый тест:

1. Откройте AutoVPN
2. Добавьте простое приложение (например, Telegram)
3. Откройте Telegram
4. Outline должен запуститься

Если с Telegram работает, а с YouTube нет - проблема в YouTube.
Если не работает вообще - проблема в Accessibility Service.
